# 3.2.1

## 改动

- 模块包名统一更改为 `vip.chener.musicenhance`，同步迁移源码命名空间、Xposed 入口、资源引用及内部通信标识。
- 补充 LSPosed 模块仓库摘要、用户说明和提交资料。

## 安装说明

这是包名迁移版本，Android 会将其安装为独立应用，无法覆盖旧包名版本，配置不会自动迁移。请记录旧设置，在 LSPosed 中停用旧模块，安装并启用新模块、重新设置音乐应用开关后重启手机。确认功能正常后可卸载旧模块，避免同时启用两份模块。

要求 Xiaomi MIX Flip / MIX Flip 2、HyperOS、Android 14 及以上、arm64-v8a，以及支持现代 libxposed API 102 的 LSPosed 环境。LX-X Music 和 Spotify 仍待真机验证，其他限制参见模块 README。

## 验证

本次迁移通过 584 项本地单元测试及 Release 构建。Release lint 为 0 错误、5 项警告，涉及依赖版本更新提示和 ChromeOS 架构支持。已核对构建 APK 的实际包名、版本及压缩后的 Xposed 入口；新包名的签名安装、外屏行为和内外屏切换尚待真机复测。
